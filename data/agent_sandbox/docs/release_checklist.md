# Release checklist

Current steps (use these):
1. Freeze the release branch and tag the candidate.
2. Update the changelog with every user-facing change.
3. Run the full test suite and the smoke tests on staging.
4. Get sign-off from the release owner, then deploy.

## Deprecated steps (ignore)
These were for the old build server and no longer apply:
- Email the build to QA by hand.
- Copy artifacts to the shared drive.
