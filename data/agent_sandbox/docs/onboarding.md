# Engineering onboarding

## First-week checklist
1. Get access to the workspace and the document index.
2. Read the style guide in docs/style_guide.md.
3. Pair with your onboarding buddy on a starter task.
4. Run the test suite locally and open a trivial PR to learn the flow.
