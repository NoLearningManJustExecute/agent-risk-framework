AI agent security / measurement

Measuring what a guardrail actually buys.

A local, offline lab that builds a deliberately over-permissioned LLM agent, attacks it, defends it with six layered controls, and measures how much each control cuts attack success and what it costs in false positives.

The finding

Architecture beat the classifier on both axes.

Each control was measured alone against the undefended baseline, N=10 per case at temperature 0. The deterministic least-privilege layer cut more attack success than the content classifier, at a fraction of the usefulness cost.

How it works

Build it, attack it, measure the defense.

01

Vulnerable agent

An over-permissioned agent with three fake tools behind a local stdio MCP server. Synthetic data, no real network, mailbox, or files.

02

Attack library

Twelve attack cases with obfuscated variants, scored by deterministic oracles against the tool-call log. No LLM judge.

03

Ablation

Each control alone and combined, N=10 at fixed seed, every rate reported with its denominator and its outcome buckets.
